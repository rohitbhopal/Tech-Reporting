# FieldMaster - Field Service Management

A static landing page for a field service management product, built with HTML and CSS.

## What it shows
- Role-based sections for Field Technician, Field Supervisor, and Operations Manager
- Feature overview, testimonials, FAQ, and contact sections

## Tech
- HTML, CSS, and small inline JavaScript for tabs and the FAQ accordion

## Run it
Open index.html in a browser, or serve the folder with any static file server.
